# stop.bat 验收

- 根目录 `stop.bat` 调用 `scripts/stop.mjs`，停止范围是当前项目。
- 新启动器和 `npm run serve` 使用本机会话记录与带随机凭据的命名管道请求正常退出；控制接口不在游戏 HTTP 服务中公开。
- 旧版/遗留进程仅按完整入口路径识别。当前旧版相对路径 `serve.mjs` 的进程已按 PID、可执行文件、完整命令行和精确创建时间登记；执行前重新核对，避免 PID 被重用后误停其他进程。
- 原有用户服务只执行了识别检查，未在测试中终止。
- `node qa/stop-smoke.mjs` 在独立临时项目中验证：两个受控实例正常退出、遗留服务器停止、端口释放、其他项目的同名服务保留、重复执行正常。所有测试进程和临时目录已清理。
- `node qa/launcher-smoke.mjs` 验证原有启动、Enter 退出与端口避让正常。
- `npm test`：103 项通过。

停止服务会断开公网分享；已经在浏览器中完整载入的单机页面可能继续运行，需要自行关闭。此操作不保存或暂停游戏进度。再次运行 `start.bat` 可重新启动。
