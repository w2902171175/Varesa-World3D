## 对本便利店的具体建议

下列是基于截图的**项目适配建议**，不是声称原神具有本项目的购物、付款或收据规则。

- 使用大面积背包覆盖层：顶部分类、左侧图标网格、右侧详情、右下固定主动作。桌面可用约 2:1 的网格/详情宽度比例；网格先做 6–8 列，再随窗口缩窄。顶部页签参考 B，而不是误称 A 也采用顶部页签。
- 分类只保留本场景需要的“食品 / 饮品 / 随身工具 / 收据”；待付款购物篮另设清楚的入口或状态，不把未付款数量混进已购可用数量。
- 卡片使用可辨认的商品或工具图标，底部显示实际数量，选中时出现浅色描边。右侧放更大的同一图标、名称、简短描述、数量、价格和付款状态。参考图里的星级属于原游戏系统，本项目不应无缘无故给雨伞、饭团加星级。
- **“选中查看”与“手持 / 装备”分开。** 点卡片只更新右侧详情；食品通过“食用 / 饮用”，工具通过“手持 / 装备 / 收起”执行动作。真正手持或装备的物品另加状态徽标，不能仅用选中描边表示。
- 主动作固定在右下：已付款食品可用；未付款食品显示禁用原因“请先结账”；工具反映真实装备状态；收据显示小票明细与总额，不出现食用按钮。数量和状态改变后即时刷新，但保持当前选中卡片和滚动位置。
- 背包打开时释放鼠标、暂停人物移动与自由视角输入，关闭后恢复；卡片网格和长详情各自滚动，分类与主动作保持可见。这是本项目的操作建议，单张截图本身不能证明所有原游戏模式都会暂停。
