# 动作与视角重做

使用 Three.js 0.170.0，保留原模型和便利店场景。

实机参考：原神官方《拾枝杂谈—瓦雷莎：英雄登场！》
https://www.bilibili.com/video/BV1PMXNYtE9A/

在浏览器播放器中实际查看了接敌、站立及技能展示画面，包括约 01:02、00:36 的画面。用于观察整体姿态、画面中人物比例和稳定的观察方向，未从游戏提取动作或相机参数。参考截图保存在此目录。

本轮以视觉结果为重点，完成以下更换：

- 原来的全身脚部目标求解替换为 CMU 35_01 / 35_17 的完整动捕周期重定向。侧面连续预览中可见直立的躯干、较伸展的支撑腿和正常摆动的回收腿，避免此前持续屈膝的姿态。
- 相机取消所有自动左右绕行，只沿用户选择的视线缩短、恢复距离。
- 交互统一为 F，HUD、提示、无障碍说明和操作文件同步修改，R 次要操作保留。
- 支持点击画面申请鼠标锁定；内置预览中申请未成功时，拖动方式仍然可用，不会阻断游玩。
- 新步态的来源、处理方式和声明见 assets/motion/SOURCE.md，离线包包含其副本。

测试检查真实蒙皮、动捕方向重定向、站立高度、地面校正幅度、过渡、帧率一致性以及相机方向归属。旧的“脚踝完全锁地”要求已不再用于推动身体下蹲。
