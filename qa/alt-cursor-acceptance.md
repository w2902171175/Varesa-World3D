# Alt 临时鼠标模式验收

行为：按住左右任一 Alt 显示鼠标，阻止鼠标转向和滚轮调整视距；松开全部 Alt 后恢复原来的视角状态。背包、读物、Esc 暂停保持自己的状态。失焦清理按键，返回场景点击恢复。

浏览器原生输入检查（本地 4180，v7）：

- 普通鼠标移动：光标 `none`，跟随开启，相机 yaw 为 -0.140。
- 连续两次带 Alt 的鼠标移动：光标 `default`，临时鼠标模式开启，跟随关闭，yaw 保持 -0.140。
- 松开 Alt 的首个移动：yaw 仍为 -0.140；下一次普通移动更新为 0.105，没有补算按住期间的位移。
- Alt 点击环境音按钮成功切换；Alt 点击背包成功打开，松开后面板保持自由光标。
- Esc 暂停后按住、松开 Alt：仍为自由光标，yaw 保持不变；点击场景后恢复转向。
- 页面未记录 JavaScript 错误。

输入模块测试另外覆盖左右 Alt、重复 keydown、窗口外已按下 Alt、丢失 keyup、面板/手动暂停优先级与奔跑模式保留。异步 Pointer Lock 解锁后恢复请求由代码状态审查覆盖；当前内嵌浏览器的实际试玩使用普通鼠标移动路径。
